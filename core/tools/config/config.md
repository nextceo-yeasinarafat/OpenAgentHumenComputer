# config (`core/tools/config`)

A computer being made: the box that asks the questions, the identity and
the hardware of the answer, and the log the making speaks through.

## Files

| File | What it does |
| --- | --- |
| `core_config.ts` | the identity of the computer (name, account, password, country, language, zone) and its rules; the ask to the bridge (`/api/create`) |
| `core_config.tsx` | the box: three sliding pages — identity, hardware, the summary — drawn in the ground of the machine |
| `config_data.ts` | the real world tables: countries, languages, the time zones of each |
| `config_hardware.ts` | what the host machine really has, so the sliders begin at the truth |
| `config_logs.ts` | the log of a making: every line of it, kept so a refresh replays it |
| `config.md` | this document |
