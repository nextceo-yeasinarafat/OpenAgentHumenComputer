# loading (`core/tools/loading`)

The moment before the computer arrives. Every entry — a first visit or a
refresh — is covered by this page: three seconds of the dark the desktop
wears, the logo turning its slow turn in the middle, then a smooth fade.

## Files

| File | What it does |
| --- | --- |
| `core_loading.ts` | the timings and the styles: the three-second hold, the six-hundred-millisecond fade, the logo of the machine |
| `core_loading.tsx` | the page itself: #0E0E0E, the logo in its exact middle |
| `loading.md` | this document |

Under the cover the real page asks the bridge what is true, so the cover
never hides a half-drawn screen — it hides the asking, and lifts on a
finished answer.
